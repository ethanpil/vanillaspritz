RSVP Reader

Speed-read any web page, one word at a time.

Drag this button to your bookmarks bar to install:

📖 RSVP Reader

Clicking it here does nothing useful — drag it to the bookmarks bar, then click it on any article. If the bookmarks bar is hidden, press Ctrl+Shift+B (⌘+Shift+B on Mac) first.

How to use

  • Select the text you want to read, or let it auto-detect the main content
  • Click the bookmarklet, pick a speed, press Start
  • Space pause/resume · ← rewind 10 words · Esc close

No analytics, no external scripts, no network calls — everything runs locally in the page.
