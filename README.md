# RSVP Reader
RSVP Reader is a bookmarklet and Chrome extension utilizing the [Rapid Serial Visual Presentation](https://en.wikipedia.org/wiki/Rapid_serial_visual_presentation) (RSVP) method, where words are displayed one at a time in a fixed position to improve reading speed and comprehension. RSVP Reader does not contain any analytics, does not use any external scripts or libraries and does not make any AJAX calls.

## Installation

### Bookmarklet
**Easiest:** open the **[install page](https://ethanpil.github.io/rsvpreader/)** and drag the **📖 RSVP Reader** button to your bookmarks bar. (GitHub strips `javascript:` links from READMEs, so the draggable link lives on that page.)

**Manual:** create a new bookmark in your browser and paste the following code as its URL. Then click the bookmark on any page to open the reader.

### Chrome Extension
1. Download `rsvp-reader-extension.zip` from the [latest release](https://github.com/ethanpil/rsvpreader/releases/latest) and unzip it.
2. Open `chrome://extensions`, enable **Developer mode**, and click **Load unpacked**.
3. Select the unzipped folder, then click the RSVP Reader toolbar icon on any page.

## Usage
* Highlight the text you want to read (or let RSVP Reader auto-detect the main content)
* Activate the bookmarklet or extension icon
* Select the WPM and Start reading
* You can pause/resume the reading and adjust the WPM during reading (your WPM choice is remembered)
* Keyboard shortcuts: **Space** = pause/resume, **Esc** = close, **←** = rewind 10 words

## Building
```
npm install
npm run build
```
This produces `dist/bookmarklet.txt`, `dist/rsvp-reader.min.js`, and an unpacked Chrome extension in `dist/extension/`, and refreshes the bookmarklet code above and the draggable link on the [install page](https://ethanpil.github.io/rsvpreader/) (`docs/index.html`). Tagged pushes (`v*`) trigger a GitHub Action that attaches the built extension zip and bookmarklet to a release.
